### Descripción del Proyecto
Este proyecto analiza los factores asociados a la permanencia operativa de startups aceleradas por Y Combinator. El estudio considera características como el uso de inteligencia artificial, la industria a la que pertenece cada empresa, la actividad de contratación y la antigüedad de las startups dentro del ecosistema Y Combinator.

El proyecto fue desarrollado utilizando Python, Jupyter Notebook y Git/GitHub, siguiendo una metodología reproducible basada en las fases F1–F4 del curso.

### Fuente de Datos
